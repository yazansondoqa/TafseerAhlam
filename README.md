# موقع تفسير الأحلام — دليل الاستخدام والنشر

## نظرة عامة

موقع عربي متخصص في تفسير الأحلام والرؤى حسب التراث الإسلامي. يعتمد على كتب أربعة من كبار علماء تعبير الرؤى: **ابن سيرين**، **النابلسي**، **ابن شاهين الظاهري**، و**الإمام جعفر الصادق**.

## التشغيل المحلي

### الطريقة الأولى: تشغيل الخادم الموصى به
```
انقر نقراً مزدوجاً على: تشغيل الموقع.bat
```
سيبدأ الخادم على `http://localhost:8080` ويفتح المتصفح تلقائياً.

### الطريقة الثانية: فتح مباشر
```
انقر نقراً مزدوجاً على: فتح مباشرة.bat
```
يفتح `index.html` مباشرة في المتصفح (يعمل لكن الخادم أفضل).

### الطريقة الثالثة: يدوياً عبر PowerShell
```powershell
.\Server.ps1 -Port 8080
```

## الإعدادات القابلة للتغيير

**كل الإعدادات في ملف واحد:** `js/config.js`

| الإعداد | الوصف |
|---------|-------|
| `siteName` | اسم الموقع |
| `siteUrl` | رابط الموقع النهائي (بعد ربط النطاق) |
| `adsense.enabled` | تفعيل/تعطيل الإعلانات |
| `adsense.client` | معرّف ناشر أدسنس |
| `adsense.slots.*` | أرقام الوحدات الإعلانية |
| `contact.email` | بريد التواصل |

## النشر على Cloudflare Pages

### الخطوات:

1. **أنشئ حساباً** على [Cloudflare Pages](https://pages.cloudflare.com/)

2. **ارفع الموقع** بطريقتين:

   **أ) عبر Git (موصى به):**
   - ارفع المشروع إلى GitHub/GitLab
   - في Cloudflare: Create project → Connect to Git → اختر المستودع
   - Build settings:
     - Build command: *(اتركه فارغاً)*
     - Output directory: *(اتركه فارغاً)*

   **ب) عبر رفع مباشر:**
   - في Cloudflare: Create project → Upload assets
   - اسحب مجلد الموقع ورفعه

3. **ربط النطاق المخصص** (اختياري):
   - Custom domains → Set up a custom domain
   - أدخل نطاقك (مثل `tafsir-ahlam.com`)
   - سيوجه Cloudflare إعدادات DNS تلقائياً

4. **حدّث `siteUrl`** في `js/config.js` إلى النطاق الحقيقي

## تفعيل Google AdSense

### المتطلبات:
- أن يكون الموقع منشوراً على نطاق حقيقي
- أن يحتوي على صفحات: سياسة الخصوصية، شروط الاستخدام، اتصل بنا، عن الموقع ✓

### الخطوات:

1. سجل في [Google AdSense](https://www.google.com/adsense/)
2. أضف موقعك واطلب المراجعة
3. بعد القبول، انسخ معرّف الناشر (Publisher ID)
4. افتح `js/config.js` وغيّر:
   ```js
   adsense: {
       enabled: true,
       client: "ca-pub-XXXXXXXXXXXXXXXX",  // ← ضع معرّفك هنا
   }
   ```
5. أنشئ وحدات إعلانية في لوحة أدسنس وانسخ أرقامها إلى `slots`
6. انشر الموقع

```js
    "ibn-shahin": "نص التفسير...",
    "jafar": "نص التفسير..."
}},
```

## الأداء

- لا صور ثقيلة — كل الأيقونات هي رموز Unicode
- خطوط Google Fonts تُحمَّل بكفاءة مع `display=swap`
- ملفات CSS وJS صغيرة ومحسّنة
- ترويسات أمان وتخزين مؤقت عبر Cloudflare
